# ทดสอบตัวอ่าน QR ของตู้บนคอม (ไม่ต้องมีบอร์ด)

ใช้ `quirc` ซอร์สเดียวกับในตู้ (หลัง `firmware/patch_quirc.py`) และ `firmware/src/qr_scan.h` ตัวจริง — สิ่งที่ทดสอบคือโค้ดที่ลงบอร์ด

```powershell
python -m venv .venv
.venv\Scripts\pip install ziglang pillow numpy qrcode
pio run -d firmware -e esp32cam          # ครั้งแรก: ให้ patch_quirc.py แพชไลบรารี
.venv\Scripts\python firmware\test\qr_host\qr_host_test.py
```

- สร้างภาพจำลองบัตรเจ้าหน้าที่บนจอมือถือผ่านกล้องตู้ (เบลอ เอียง สัญญาณรบกวน JPEG โทนม่วง) ทั้ง **ภาพกระจก** (แบบกล้องตู้จริง) และแบบปกติ ทั้ง QVGA/VGA
- รหัสออก 1 ถ้าอัตราอ่านได้ต่ำกว่าเกณฑ์ หรืออ่านมั่ว หรือรอบสอง (ลับขอบ) ทำงานเปล่าเมื่อไม่มี QR
- แก้ `qr_scan.h` / `patch_quirc.py` / อัปเดตไลบรารี `ESP32QRCodeReader` → รันซ้ำก่อนส่งงานเสมอ

## ที่มา (2026-11-19)
ภาพจริงจากตู้ (QR กระดาษ เอียง เบลอ ขอบขาวแคบ): quirc ของไลบรารีอ่านไม่ได้ทุกค่า · ZXing อ่านได้ที่ 640×480 ·
เทียบกับ QR ที่ถูกต้อง ตารางโมดูลที่ quirc สุ่มได้ผิดแค่ 5.6% เมื่อสลับแถว-คอลัมน์ (ผิด 40% เมื่อไม่สลับ) = **ภาพจากกล้องเป็นภาพกระจก**
quirc อ่านภาพกระจกไม่ได้เลย (จำลอง: 0%) · `qr_scan.h` กลับด้านเอง + สุ่มภาพเทา + รอบสองลับขอบ → จำลอง 92–97% · ภาพจริงถอดได้ทั้ง 640×480 และ 320×240
