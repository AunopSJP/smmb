# ESP32-CAM · ดูภาพสดผ่าน Wi-Fi ของบอร์ด

โปรไฟล์ `camap` ใช้กับ AI Thinker ESP32-CAM ผ่าน Arduino-ESP32 และเสิร์ฟหน้าเว็บกับสตรีม MJPEG จากบอร์ดโดยตรง รองรับสตรีมหนึ่งรายการพร้อมกัน

จากโฟลเดอร์หลักของโปรเจกต์

```powershell
pio run -d firmware -e camap
pio run -d firmware -e camap -t upload --upload-port COM20
pio device monitor --port COM20 --baud 115200
```

1. ถ้าใช้อะแดปเตอร์ USB-to-Serial ที่เข้าโหมดแฟลชเองไม่ได้ ให้ต่อ GPIO0 ลง GND แล้วกด RST ก่อนอัปโหลด เมื่อแฟลชเสร็จให้ถอด GPIO0 ออกจาก GND แล้วกด RST อีกครั้งโดยเปิด Serial Monitor ไว้
2. ต่อ Wi-Fi `ESP32-CAM-xxxxxx` ด้วยรหัสจากบรรทัด `Password:` ใน Serial Monitor บอร์ดสร้างรหัสใหม่ทุกครั้งที่บูต
3. เปิด [http://192.168.4.1/](http://192.168.4.1/) หากมือถือแจ้งว่า Wi-Fi ไม่มีอินเทอร์เน็ต ให้เลือกเชื่อมต่อเครือข่ายนี้ต่อ
4. ในหัวข้อ **รายละเอียดภาพ** เลือกความละเอียดและคุณภาพ JPEG แล้วกด **ใช้การตั้งค่า** สตรีมจะเปิดใหม่ด้วยค่าที่เลือก บอร์ดใช้ค่าเริ่มต้นอีกครั้งเมื่อรีบูต

หน้าเว็บอ่านค่าจาก `GET /settings` และส่งค่าผ่าน `PUT /settings` ด้วยข้อความสองหลัก โดยหลักแรกคือขนาดภาพ (0 = 160×120, 1 = 320×240, 2 = 640×480 เมื่อมี PSRAM) และหลักที่สองคือคุณภาพ (0 = สูง, 1 = มาตรฐาน, 2 = ประหยัดข้อมูล) ทั้งสองคำขอส่งคืน JSON ที่มี `resolution`, `quality` และ `maxResolution` เป็นดัชนีตัวเลือก

ถ้าหน้าเว็บเปิดได้แต่ไม่มีภาพ ให้ดูบรรทัด `Camera:` และ `Stream server:` ที่ Serial Monitor หากต้องการกลับไปใช้เฟิร์มแวร์ตู้ ให้แฟลชโปรไฟล์ `esp32cam` ผ่านสาย

ถ้าเห็น `Brownout detector was triggered` ตอนเปิด Wi-Fi ให้ตรวจแหล่งจ่ายไฟ สำหรับบอร์ด AI Thinker ให้ใช้ไฟ 5 V ที่นิ่งกับขา 5V และ GND ของบอร์ด หากแยกไฟจากตัวแปลง USB-to-Serial ให้ต่อ GND ร่วมกันและถอดสาย VCC ของตัวแปลงออก
