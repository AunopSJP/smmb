# SMMB Firmware Flasher (Windows)

โปรแกรมแฟลชเฟิร์มแวร์บอร์ด **ESP32-CAM (AI-Thinker)** สำหรับทีมฮาร์ดแวร์

## ไฟล์ที่ต้องใช้

- โปรแกรม: `app/SMMB-Firmware-Flasher.exe`
- เฟิร์มแวร์: `firmware/firmware-<เวอร์ชัน>.bin`
- ไฟล์ประกอบการแฟลชเต็มรูปแบบ (ต้องมีในโฟลเดอร์ `firmware` เดียวกัน):
  - `bootloader.bin` → เขียนที่ `0x1000`
  - `partitions.bin` → เขียนที่ `0x8000`
  - `boot_app0.bin` → เขียนที่ `0xe000`
  - `firmware-<เวอร์ชัน>.bin` → เขียนที่ `0x10000`
- เครื่องมือแฟลช: Python + `esptool` หรือ PlatformIO (โปรแกรมจะหาเองอัตโนมัติ)

> ถ้าไม่มี `bootloader.bin` / `partitions.bin` โปรแกรมจะเขียนเฉพาะแอปที่ `0x10000` ซึ่งใช้ได้เฉพาะบอร์ดที่ยังมี bootloader เดิมอยู่ — **ถ้าเพิ่งล้างข้อมูลบอร์ด ต้องแฟลชเต็มรูปแบบเท่านั้น บอร์ดจึงจะบูต**

## สิ่งที่เปลี่ยนในรุ่นนี้

- **แฟลชเต็มรูปแบบ** — เขียน bootloader + partition table + boot_app0 + แอป ครบชุด เพื่อให้บอร์ดบูตได้แม้เพิ่งล้าง flash
- **แสดงเฉพาะบอร์ดที่เสียบอยู่ตอนนี้** — ตรวจจาก USB serial device ที่ Windows มองเห็น (`Get-PnpDevice -PresentOnly`) และล้างรายการทันทีเมื่อถอดบอร์ด ไม่แสดงประวัติพอร์ตเก่า/พอร์ต virtual
- **ล้างข้อมูลบอร์ดได้** — เลือกบอร์ดแล้วกด `ล้างข้อมูลบอร์ด` → ยืนยันอีกครั้ง (คำสั่ง `esptool erase-flash`) ข้อมูลทั้งหมดบน flash จะหาย บอร์ดจะไม่บูต/ไม่แจกไวไฟจนกว่าจะแฟลชใหม่
- **ระบุบอร์ดด้วยการถอด/เสียบ USB** — กดปุ่มนี้ แล้วถอดสาย USB ของบอร์ดที่ต้องการออก รอ 2–3 วินาที แล้วเสียบกลับช่องเดิม โปรแกรมจะจับคู่พอร์ตที่หายไปและกลับมา แล้วเลือกบอร์ดนั้นให้อัตโนมัติ ใช้ยืนยัน **ก่อนแฟลช** ได้ ไม่แฟลช ไม่ส่งคำสั่ง ไม่แก้โค้ดบอร์ด และใช้ได้แม้บอร์ดถูกล้าง/ยังไม่มีเฟิร์มแวร์
- **เลือกเวอร์ชันจากไฟล์จริง** — เรียงจากใหม่ไปเก่าและป้าย "แนะนำ" มาจากไฟล์ล่าสุด ไม่ได้ฮาร์ดโค้ดเวอร์ชัน
- **หน้าจอ dashboard + แถบปุ่มลอยล่าง** — การ์ดเลือกบอร์ดและเวอร์ชัน, ปุ่ม `เริ่มแฟลช` อยู่ในแถบล่างตลอดเวลา; หน้าต่างแคบยุบการ์ดเป็นคอลัมน์เดียวและปุ่มยังเห็นตลอด
- **สถานะและคำเตือนชัดเจน** — กำลังทำงาน/สำเร็จ/ผิดพลาด, แฟลชเต็มรูปแบบ/เฉพาะแอป, และยืนยันก่อนล้างข้อมูล
- รองรับ `esptool` v4 และ v5 (`write-flash`/`write_flash`, `erase-flash`/`erase_flash`)

- **เลือกไฟล์ .bin จากเครื่อง** — ปุ่ม `เลือกไฟล์ .bin จากเครื่อง…` ในการ์ดเวอร์ชันเปิดหน้าต่างเลือกไฟล์ของ Windows ไฟล์ต้องเป็น .bin ขนาด 64 KB–3 MB และไบต์แรก 0xE9 (อิมเมจ ESP32) ไม่ผ่านจะแจ้งเหตุผล ไฟล์ที่เลือกเขียนที่ `0x10000` ส่วน bootloader/partitions ใช้ชุดจากโฟลเดอร์ `firmware` ตามเดิม · ปุ่ม `ล้าง` เอาออกจากรายการ
- **Responsive UI** — หน้าต่างย่อได้ถึง 340×480: <600px โหมดกะทัดรัด (ซ่อนข้อความรอง ลดระยะขอบ ปุ่มล่างเรียงสองปุ่มเต็มแถว) · <760px การ์ดเรียงลงมาคอลัมน์เดียว · ≥760px สองคอลัมน์สูงเท่ากัน · จอกว้างขยายเนื้อหาได้ถึง 1240px · ความสูงรายการบอร์ด/เวอร์ชันปรับตามความสูงหน้าต่าง · รายการเวอร์ชันเหลือคอลัมน์เดียวเมื่อการ์ดแคบ

## หมายเหตุเรื่องโหมดตั้งค่า Wi-Fi

เฟิร์มแวร์จะแจกไวไฟ `MAILBOX-xxxxxx` เมื่อ **ยังไม่ได้ตั้งค่า Wi-Fi/box** เท่านั้น ถ้าบอร์ดเคยตั้งค่าไว้แล้ว การแฟลชทับจะไม่ล้างค่าเดิม ให้กด `ล้างข้อมูลบอร์ด` ก่อน แล้วจึงแฟลชใหม่ เพื่อให้บอร์ดกลับเข้าสู่โหมดตั้งค่าและแจกไวไฟ

### Samsung / Android ไม่เด้งไปหน้า 192.168.4.1

iPhone มักเปิด captive portal ให้อัตโนมัติ ส่วน Samsung/Android บางรุ่น (โดยเฉพาะเมื่อเปิด mobile data หรือ "Switch to mobile data") จะไม่เด้ง วิธีที่ใช้ได้:

1. ต่อ Wi-Fi `MAILBOX-xxxxxx`
2. ถ้ามี notification "Sign in to network / เข้าสู่ระบบเครือข่าย" ให้กด
3. ถ้าไม่เด้ง: เปิด Chrome หรือ Samsung Internet แล้วพิมพ์ `http://192.168.4.1` (ต้องเป็น http)
4. ปิด mobile data ชั่วคราว หรือปิด "Switch to mobile data / สลับไปใช้ข้อมูลมือถือ" สำหรับ Wi-Fi นี้
5. ถ้ายังไม่ได้: ตั้งค่า → การเชื่อมต่อ → Private DNS → ปิดชั่วคราว แล้วลองใหม่
6. ลืม Wi-Fi นี้ แล้วต่อใหม่

เฟิร์มแวร์ **0.2.13** ปรับหน้า portal ให้เป็น responsive, เพิ่มคำแนะนำ `192.168.4.1` บนหน้าแรก และเพิ่ม handler สำหรับ captive portal probe ของ Android/Samsung/iOS/Windows แล้ว

## วิธีใช้

1. เสียบสาย USB ของบอร์ด
2. เลือกบอร์ด (COM port) ที่แสดง — ถ้ามีบอร์ดเดียวโปรแกรมจะเลือกให้
3. ถ้าไม่แน่ใจว่าเลือกถูกตัว: กด `ระบุบอร์ดด้วยการถอด/เสียบ USB` → ถอดบอร์ดที่ต้องการออก รอ 2–3 วินาที → เสียบกลับช่องเดิม
4. เลือกเวอร์ชันเฟิร์มแวร์
5. กด `เริ่มแฟลช` แล้วรอ 1–2 นาที (ห้ามถอดสาย)
6. ถ้าเชื่อมต่อไม่ได้: กด `BOOT (IO0)` ค้างไว้ → กด `RST` 1 ครั้ง → ปล่อย `BOOT` แล้วลองใหม่

## ตัวติดตั้ง (Setup) สำหรับส่งให้เครื่องอื่น

ไฟล์: `installer/dist/SMMB-Firmware-Flasher-Setup.exe` (~11 MB) — ดับเบิลคลิกเครื่องปลายทางได้เลย ไม่ต้องใช้สิทธิ์แอดมิน

- ติดตั้งที่ `%LOCALAPPDATA%\Programs\SMMB Firmware Flasher` พร้อมโฟลเดอร์ `firmware` (bootloader + partitions + boot_app0 + ทุกเวอร์ชันที่มี)
- สร้างไอคอนบนเดสก์ท็อปและเมนู Start (ใช้โลโก้แอป) · ลงทะเบียนใน "แอปที่ติดตั้ง" ถอนได้จาก Settings
- ถ้าเครื่องยังไม่มี `esptool` และมี Python อยู่แล้ว จะถามว่าติดตั้งให้ (`pip install --user esptool`, ต้องต่อเน็ต) · ถ้าไม่มี Python จะแจ้งให้ติดตั้งจาก python.org (ติ๊ก Add to PATH)
- สร้างใหม่หลัง build exe / เพิ่มไฟล์เฟิร์มแวร์: `powershell -ExecutionPolicy Bypass -File installeruild-setup.ps1` (ใช้ IExpress ที่มีใน Windows)

## Build

```powershell
cd firmware-program/app
cargo build --release --offline --locked
Copy-Item target-build\release\smmb-firmware-flasher.exe SMMB-Firmware-Flasher.exe -Force
```

## QA flags

- `--demo` — แสดงข้อมูลตัวอย่าง (บอร์ด COM3/COM7) และปิดการแฟลชจริง
- `--size <กว้าง>x<สูง>` — กำหนดขนาดหน้าต่างเอง เช่น `--size 360x700` (มือถือ) / `820x900` (แท็บเล็ต) / `1920x1000`
- `--custom-firmware <path>` — ใส่ไฟล์จากเครื่องล่วงหน้า (ใช้ตรวจ UI)
- `--small` — เปิดหน้าต่างขนาด 760×640 สำหรับตรวจ layout responsive
- `--wide` — เปิดหน้าต่างขนาด 1536×864 สำหรับตรวจ layout จอกว้าง (เทียบเท่า 1920×1080 ที่ scaling 125%)
- `--screenshot <path>` — ถ่ายภาพหน้าจอแล้วปิดโปรแกรม (ใช้ตรวจ UI)
