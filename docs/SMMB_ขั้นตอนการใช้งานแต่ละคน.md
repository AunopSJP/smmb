# ขั้นตอนการใช้งาน Smart Mailbox (SMMB) แยกตามผู้ใช้
อ้างอิงผัง SMMB_Flowchart_v11.drawio · อัปเดต 22 ต.ค. 2026
**อัปเดต 27 ต.ค. 2026** : ไรเดอร์กดปุ่มหน้าตู้แทนสแกน QR ได้ · แพ็กเกจของเจ้าของบ้าน (เริ่มต้นฟรี) · หัวหน้าเห็นทุกโซน + ตัวกรอง "โซนของฉัน"

สารบัญ : ช่าง · เจ้าของบ้าน · หัวหน้าหน่วยงาน · เจ้าหน้าที่ · ไรเดอร์ · ตู้ · แอดมิน · **งานเบื้องหลังของเซิร์ฟเวอร์** (ท้ายเอกสาร)

> 📝 **เรื่อง Log:** ทุกครั้งที่มีการสแกนหรือพิมพ์รหัส ระบบบันทึกไว้เสมอ **แม้ไม่ผ่าน** — ใคร · ตู้ไหน · QR ใบ 1 / ใบ 2 / Activate · สแกนหรือพิมพ์รหัส · ผล · เวลา · การกดปุ่มส่งของหน้าตู้ก็บันทึกเช่นกัน

## 🔧 ช่าง : ติดตั้งตู้ (ครั้งเดียวต่อบ้าน)

**1. ติดตั้งอุปกรณ์**
- ติดตู้หน้าบ้าน + ติดแผงโซลาร์ให้รับแดด (ไม่มีเงาบัง)
- ติด **QR ใบ 1** ที่หน้าตู้
- เก็บ **QR ใบ 2 (สำรอง)** และ **Activate QR** ไว้ด้านในตู้

**2. เปิดตู้ครั้งแรก**
- ต่อไฟ → ตู้ยังไม่รู้จัก Wi-Fi บ้าน → ไฟกะพริบ + ปล่อยสัญญาณ `MAILBOX-XXXXXX`

**3. ตั้ง Wi-Fi ให้ตู้**
- มือถือต่อ `MAILBOX-XXXXXX` → หน้าตั้งค่าเด้งขึ้นมา → เลือก Wi-Fi บ้าน (2.4 GHz) → ใส่รหัส → กดเชื่อมต่อ
  - หน้าตั้งค่าไม่เด้ง → ปิดเน็ตมือถือ แล้วเปิด `192.168.4.1` เอง

**4. ดูไฟที่ตู้**
- 🟢 ไฟเขียว → ตู้ต่อเน็ตได้ → ไปข้อ 5
- 🔴 ไฟแดง → ต่อไม่ได้ → กลับไปข้อ 3 (เช็กรหัส / เช็กว่าเป็น 2.4 GHz)

**5. ทดสอบ**
- ดูในหลังบ้านว่าตู้ออนไลน์ + แบตกำลังชาร์จ
- สแกนทดสอบ **QR ใบ 1 และใบ 2** → ตู้ตื่น + กล้องเปิด
- **กดปุ่มส่งของหน้าตู้** 1 ครั้ง → ไฟเขียว + หลังบ้านเห็นรายการส่งของ (เพิ่ม 27 ต.ค.)
  - สัญญาณไม่ถึง → ย้ายจุดติดตั้ง หรือเพิ่มตัวขยายสัญญาณ
  - ทดสอบไม่ผ่าน → แก้ไข / แจ้งทีมฮาร์ดแวร์ → ทดสอบใหม่

**6. ส่งต่อเจ้าของบ้าน**
- ให้เจ้าของบ้านสมัครและผูกตู้ต่อหน้าช่าง

## 🏠 เจ้าของบ้าน

### ครั้งแรก : สมัครและผูกตู้

**1. เปิดลิงก์เว็บแอป**
- เปิดใน LINE → ระบบบอกให้เปิดใน Safari / Chrome (ใน LINE แจ้งเตือนไม่ทำงาน)

**2. ติดตั้งเป็นแอป**
- iPhone → ระบบสอน "แชร์ → เพิ่มไปยังหน้าจอหลัก" → เปิดจากไอคอน
- Android → ใช้ต่อได้เลย

**3. เปิดแจ้งเตือน**
- กดอนุญาต → ได้แจ้งเตือนทดสอบ 1 ครั้ง
  - ข้ามได้ แต่หน้าหลักจะมีแถบเตือนค้างไว้

**4. สมัครสมาชิก**
- กรอก ชื่อ · เบอร์ · รหัสผ่าน · บ้านเลขที่ → ยอมรับข้อตกลง
  - ไม่ยอมรับ → ไม่สร้างบัญชี
- สมัครสำเร็จ → บัญชีได้**แพ็กเกจฟรี**อัตโนมัติ (เพิ่ม 27 ต.ค. — แพ็กผูกกับบัญชี ใช้กับทุกตู้ของเจ้าของคนนี้)

**5. ผูกตู้**
- เปิดฝาตู้ → สแกน **Activate QR** → ตั้งชื่อตู้ → ✅ ตู้เป็นของคุณ
  - สแกนไม่ได้ → พิมพ์รหัสใต้ QR
  - รหัสผิด → "QR ไม่ถูกต้อง" (บันทึก Log)
  - ตู้มีเจ้าของแล้ว → "ตู้ถูกผูกแล้ว กรุณาติดต่อผู้ดูแล"
  - Activate QR ใช้ได้ครั้งเดียว

**6. เข้าหน้าหลัก**
- ช่วงแรกขึ้นว่า "ยังไม่มีเจ้าหน้าที่ดูแล" จนกว่าหัวหน้าจะเพิ่มบ้านเข้าโซน

### ใช้งานทุกวัน

**หน้าหลักแสดง** : สถานะตู้ · แบต · ติดต่อล่าสุดเมื่อไหร่ · เหตุการณ์ล่าสุด · ปุ่ม SOS

**🔔 แจ้งเตือนที่ได้รับ**
- 👮 "ตำรวจ สภ.X · ส.ต.ต. สมชาย มาตรวจ 22:15"
- 🛵 "มีของมาส่ง" (บอกด้วยว่า สแกน QR หรือ กดปุ่มหน้าตู้)
- ⚠️ "ตู้ไม่ออนไลน์" → เมื่อถึงเวลาตรวจแล้วตู้ไม่ขึ้น
- 📮 "กรุณาเอา QR ใบ 2 ในตู้ไปติดแทน" → เมื่อแอดมินพบว่า QR ใบ 1 เสีย
  - เปิดตู้ → เอาใบ 2 ไปติดหน้าตู้ → กด "ติดแล้ว" ในแอป → รอรับใบสำรองใหม่

**📅 ดูประวัติ**
- กด "ประวัติ" → เลือกวันที่เริ่ม–ถึง → รายการบรรทัดเดียว + ไอคอน → แตะดูรายละเอียด

**💳 ดูแพ็กเกจ** (เพิ่ม 27 ต.ค.)
- หน้าตั้งค่า → แถว "แพ็กเกจ" → เห็นชื่อแพ็ก (ตอนนี้ = ฟรี) · วันหมดอายุ (แพ็กฟรีไม่มี) · ฟีเจอร์ที่ได้
- เปลี่ยนแพ็กเองไม่ได้ (ยังไม่มีการชำระเงิน — แอดมินเป็นคนตั้ง)

**📶 เปลี่ยน Wi-Fi บ้าน**
- แจ้งช่างผ่านแอป → รอช่างนัด
- หรือทำเอง : เปิดตู้ → กดปุ่ม Boot บนบอร์ดค้าง 5 วิ → ทำแบบช่างข้อ 3–4

### 🆘 กด SOS

**1. กดปุ่ม SOS ค้าง 3 วินาที** (กันกดโดยไม่ได้ตั้งใจ)

**2. ระบบเช็กว่าบ้านมีเจ้าหน้าที่ดูแลไหม**
- ไม่มี → ขึ้นทันที "โทร 191 / 1669" (ปุ่มใหญ่)
- มี → ส่งแจ้งเตือนหาเจ้าหน้าที่ในโซน → ไปข้อ 3

**3. หน้ารอ** "กำลังหาเจ้าหน้าที่…" + นับเวลา
- ปุ่ม [โทร 191] [โทร 1669] [ยกเลิก SOS] กดได้ตลอด

**4. ระหว่างรอ**
- 30 วิ ยังไม่มีคนรับ → ส่งหาทุกคนในหน่วยงาน + หัวหน้า
- 60 วิ ยังไม่มีคนรับ → ขึ้นตัวใหญ่ "กรุณาโทร 191 / 1669 ทันที" (SOS ยังเปิดรอคนรับต่อ)

**5. มีคนรับ** → เห็น "รับแล้วโดย ส.ต.ต. สมชาย (สภ.X)" + ปุ่มโทรหาเจ้าหน้าที่

**6. เจ้าหน้าที่ปิดเรื่อง** → เห็นหมายเหตุ → จบ

**ยกเลิก SOS**
- กด "ยกเลิก SOS" → ยืนยัน (ปลอดภัยแล้ว / กดผิด) → ระบบแจ้งเจ้าหน้าที่ว่ายกเลิกแล้ว
  - ไม่ยืนยัน → กลับหน้ารอ

## 👮‍♂️ หัวหน้าหน่วยงาน

### ครั้งแรก : ตั้งหน่วยงาน

**1. เปิดลิงก์ + ติดตั้งแอป + เปิดแจ้งเตือน** (เหมือนเจ้าของบ้านข้อ 1–3)

**2. สมัครหน่วยงาน**
- กรอก ชื่อหน่วยงาน · ประเภท (ตำรวจ / รปภ. / อื่น ๆ) · ข้อมูลหัวหน้า → ยอมรับข้อตกลง

**3. รอแอดมินอนุมัติ**
- ล็อกอินระหว่างรอ → เห็น "รอแอดมินตรวจ"
  - ไม่อนุมัติ → เห็น "ไม่อนุมัติ"

**4. ได้รับอนุมัติ**
- หน้าหลักแสดง **รหัสกลุ่ม** → ส่งให้ลูกทีมไปสมัคร

**5. ยืนยันลูกทีม**
- เมนู "สมาชิก" → คนรอยืนยันอยู่บนสุด → อนุมัติ / ปฏิเสธ

**6. สร้างโซน**
- เมนู "โซน" → ตั้งชื่อโซน → ใส่บ้าน → ใส่เจ้าหน้าที่ → ตั้งเวลาตรวจ (เช่น 06:00–09:00, 17:00–21:00)
  - 1 คนอยู่ได้หลายโซน · 1 โซนมีได้หลายคน
  - ตู้ในโซนรู้เวลาตรวจใหม่ภายใน 1 วัน

### ใช้งานทุกวัน

> **ขอบเขต (ยืนยัน 27 ต.ค.)** : หัวหน้า**เห็นและจัดการได้ทุกโซนของหน่วยงาน** · หน้าหลักกับ Log เริ่มที่ "โซนของฉัน" แล้วกดสลับเป็น "ทุกโซน" หรือเลือกโซนได้ · การตรวจตู้ยังทำได้เฉพาะโซนที่ตัวเองอยู่

- **หน้าหลัก** → ภาพรวมทีมวันนี้ (ตัวกรอง โซนของฉัน / ทุกโซน / เลือกโซน)
- **สมาชิก** → อนุมัติ / ปิดสิทธิ์ / ตั้งหัวหน้าเพิ่ม / รีเซ็ตรหัสลูกทีม
- **Log การตรวจ** → กรองตามโซน / วัน / คน / บ้าน → เห็น ใคร · บ้าน · เวลา · QR ใบไหน · สแกนหรือพิมพ์ · ผล
- **โซน** → เห็นทุกโซน (มีป้าย "โซนที่ฉันอยู่") → ย้ายคนเข้าออก (เช่น คนลา)
- **ตรวจตู้เอง** (โซนที่ตัวเองอยู่) และ **รับ SOS** ได้เหมือนเจ้าหน้าที่

## 👮 เจ้าหน้าที่

### ครั้งแรก : สมัคร

**1. เปิดลิงก์ + ติดตั้งแอป** (เหมือนเจ้าของบ้านข้อ 1–2)

**2. สมัคร**
- กรอก ชื่อ · เบอร์ · รหัสผ่าน · รหัสกลุ่มจากหัวหน้า → ยอมรับข้อตกลง

**3. รอหัวหน้ายืนยัน**
- ล็อกอินระหว่างรอ → เห็น "รอหัวหน้ายืนยัน"
  - ถูกปฏิเสธ → เห็น "ถูกปฏิเสธ"

**4. เปิดแจ้งเตือน (บังคับ)**
- ยังไม่เปิด → ใช้งานไม่ได้ (ไม่งั้นจะไม่ได้รับ SOS)

### 🔍 ตรวจตู้ (เฉพาะในเวลาตรวจ)

**1. เปิดแอป** → หน้าสรุป "บ้านในโซนของฉัน 10 หลัง · ตรวจแล้ว 5 · หลังถัดไป 99/9"

**2. ไปถึงหน้าตู้ → กด "สแกน" ในแอป**
- ครั้งแรก → เบราว์เซอร์ถามสิทธิ์กล้อง → อนุญาต
  - ไม่อนุญาตกล้อง → พิมพ์รหัสใต้ QR แทน
- ⚠️ ต้องสแกนผ่านแอปเท่านั้น (สแกนด้วยกล้องมือถือธรรมดาจะได้หน้าส่งของของไรเดอร์)
- ⚠️ อย่ากดปุ่มส่งของหน้าตู้ (ปุ่มนั้นของไรเดอร์ — กดแล้วเจ้าของบ้านจะได้แจ้งเตือน "มีของมาส่ง")

**3. สแกน QR หน้าตู้ (ใบ 1 หรือใบ 2)**
- 🛡️ แอปเช็กว่าเป็น QR ของ SMMB จริงไหม (ลายเซ็นถูกต้อง)
  - ไม่ใช่ของระบบ → ⚠️ "QR นี้ไม่ใช่ของระบบ" → แจ้งแอดมินทันที (อาจมีคนแปะ QR ปลอมทับ) → จบ
- ⏱ สแกนติดภายใน ~10 วิ → ไปต่อ
  - สแกนไม่ติด / ต้องพิมพ์รหัสแทน → แอปถาม "QR ดูเสียไหม?" (ซีด / ขาด / หาย / มีอะไรติดทับ / ปกติ)
  - 🚩 ขึ้นธงแดง QR ใบนี้ทันที (1 ครั้งก็พอ) → แอดมินเห็นภายในวันนี้ → ตรวจต่อได้ตามปกติ
- 📝 ระบบบันทึก Log ทันที : ใคร · ตู้ · QR ใบไหน · สแกนหรือพิมพ์ · เวลาที่ใช้สแกน

**4. ระบบเช็ก**
- รหัสผิด → "รหัสไม่ถูกต้อง" → สแกนใหม่
- ไม่ใช่บ้านในโซนตัวเอง → "ไม่ใช่บ้านในโซนของคุณ" → สแกนใหม่
- นอกเวลาตรวจ → "นอกเวลาตรวจ ไม่บันทึกการตรวจ" → จบ
- ผ่านทั้งหมด → ไปข้อ 5

**5. รอตู้ตื่น (1–3 วินาที)**
- เซิร์ฟเวอร์เรียกตู้ → ไฟที่ตู้ติด → กล้องตู้เปิด
  - ตู้ไม่ตอบภายใน ~30 วิ → ดูไฟที่ตู้ (ไม่ติด = ตู้ไม่มีไฟ) → กด "แจ้งปัญหาตู้" → ระบบแจ้งเจ้าของบ้าน + แอดมิน → กลับหน้าสรุป

**6. ยื่น QR ในมือถือให้กล้องตู้**
- แอปโชว์ **QR ประจำตัว** (เปลี่ยนทุก 30 วิ ถ่ายรูปไปใช้แทนไม่ได้) → หันจอเข้ากล้องตู้
- 📝 ตู้ส่งผล : UID ที่อ่านได้ · ครั้งที่ลอง · เวลา (มีลายเซ็นตู้)
  - ไม่ผ่าน → ลองใหม่ได้ 3 ครั้ง
  - ครบ 3 ครั้งยังไม่ผ่าน → แจ้งปัญหาตู้

**7. ✅ ตรวจแล้ว**
- 📝 บันทึก "ตรวจแล้ว 22:15" : ใคร · ตู้ · QR ใบไหน · วิธี · ผลตู้สแกน
- เจ้าของบ้านได้แจ้งเตือน → ตู้กลับไปพัก

**8. ไปหลังถัดไป** → ทำข้อ 2–7 ซ้ำ → ครบแล้วจบรอบ

### 🆘 รับ SOS (เข้ามาได้ทุกเวลา)

**1. ได้แจ้งเตือนสีแดง** → เห็นบ้านเลขที่ + เบอร์เจ้าของบ้าน

**2. ดูว่ามีคนรับหรือยัง**
- มีแล้ว → เห็น "รับแล้วโดย X" → กลับไปทำงานต่อ
- ยังไม่มี → กด **"รับเรื่อง"**
  - กดพร้อมกันหลายคน → ระบบให้คนแรกได้ คนอื่นเห็น "รับแล้วโดย X"

**3. ไปที่เกิดเหตุ**
- เจ้าของบ้านยกเลิกระหว่างทาง → ได้แจ้งเตือน "SOS ถูกยกเลิกแล้ว"

**4. กด "ปิดเรื่อง" + เขียนหมายเหตุ** → เจ้าของบ้านเห็นสถานะ → จบ

## 🛵 ไรเดอร์ (ไม่ต้องสมัคร ไม่ต้องลงแอป ทำได้ทุกเวลา)

แจ้งส่งของได้ **2 ทาง** — เลือกทางไหนก็ได้ (อัปเดต 27 ต.ค.)

### ทาง A : สแกน QR หน้าตู้

**1. สแกน QR หน้าตู้ด้วยกล้องมือถือ**
- QR เสีย → พิมพ์รหัสใต้ QR (หรือใช้ทาง B แทน)
- 📝 ระบบบันทึก Log ทันที : ตู้ · QR ใบไหน · สแกนหรือพิมพ์ · ผล · เวลา (ไม่เก็บว่าเป็นใคร)
- รหัสผิด → "QR ไม่ถูกต้อง" → สแกนใหม่
- ตู้ปิดบริการ → "ตู้นี้ปิดให้บริการ" → จบ

**2. เห็นบ้านเลขที่ + ปุ่ม "ส่งของ"**
- มีข้อความเล็ก ๆ "เจ้าหน้าที่ กรุณาสแกนผ่านแอป SMMB"

**3. ใส่ของลงตู้ → กด "ส่งของ"**
- 📝 บันทึก Log ส่งของ
- ✅ ส่งสำเร็จ → เจ้าของบ้านได้แจ้งเตือน
  - ระบบจำกัดจำนวนครั้งต่อตู้ กันคนกดมั่วจากรูป QR

### ทาง B : กดปุ่มที่หน้าตู้ (ไม่ต้องใช้มือถือ)

**1. ใส่ของลงตู้ → กดปุ่มส่งของที่หน้าตู้ 1 ครั้ง**
- ตู้ตื่นเอง (แม้นอกเวลาตรวจ) → ไฟกะพริบ "กำลังส่ง"

**2. ดูไฟที่ตู้**
- 🟢 เขียว → ส่งสำเร็จ → เจ้าของบ้านได้แจ้งเตือน "มีของมาส่ง (กดปุ่มหน้าตู้)"
- 🟠 ส้มกะพริบ → กดถี่เกิน (นับรวมกับการสแกน QR ของตู้นี้) → ไม่ต้องกดซ้ำ
- 🔴 แดง → ส่งไม่ได้ / ตู้ปิดบริการ → ใช้ทาง A แทน
- 📝 บันทึก Log ส่งของ : ตู้ · วิธี = กดปุ่ม · ผล · เวลา (ไม่เก็บว่าเป็นใคร)
- กดซ้ำหลายครั้งติดกัน → ตู้นับเป็นครั้งเดียว และไม่รับกดใหม่ ~30 วิ

## 📦 ตู้ (ทำงานเองตลอด — คนกดได้แค่ปุ่มส่งของหน้าตู้)

**ในเวลาตรวจ** (เช่น 06–09, 17–21 น.)
- หลับเบา ต่อ Wi-Fi ค้าง → พร้อมตื่นทันทีเมื่อเจ้าหน้าที่สแกน
- เริ่มเวลาตรวจแล้วตู้ไม่ออนไลน์ → ระบบแจ้งเจ้าของบ้าน + แอดมิน

**นอกเวลาตรวจ**
- หลับลึก ปิดทุกอย่าง → ไม่รับงานตรวจ → ตื่นเมื่อถึงเวลาตรวจ (หรือเมื่อมีคนกดปุ่มส่งของ)

**วันละครั้ง**
- ส่งสถานะ + แบต (+ จำนวนครั้งที่กดปุ่มส่งของ) → มีค่าตั้งค่าใหม่ (เช่น เวลาตรวจเปลี่ยน) → ดึงมาใช้

**เมื่อมีงานตรวจ**
- ไฟติด → เปิดกล้อง (+ ไฟส่องถ้ามืด) → สแกน QR ประจำตัว → ส่งผลพร้อมลายเซ็นตู้ → กลับไปพัก

**เมื่อไรเดอร์กดปุ่มส่งของ** (เพิ่ม 27 ต.ค.)
- ตื่น → รวมการกดใน ~3 วิ เป็นครั้งเดียว → ต่อ Wi-Fi → ส่งพร้อมลายเซ็นตู้ → ไฟบอกผล → กลับไปพัก
- ส่งไม่ได้ → ลองใหม่ 3 ครั้ง → ไม่ได้ = ไฟแดง ทิ้ง (ไม่เก็บไว้ส่งทีหลัง) + นับในรายงานรายวัน

**ถ้ามีปัญหา**
- ต่อ Wi-Fi ไม่ได้ → ไฟแดง → เข้าโหมดตั้งค่าเอง (ระหว่างนั้นยังลองต่อ Wi-Fi เดิมเป็นระยะ)
- กดปุ่ม Boot ค้าง → ลบ Wi-Fi เดิม → เข้าโหมดตั้งค่า

## 🖥️ แอดมิน (ฝั่งเรา)

- ช่างใช้บัญชีแอดมินตอนติดตั้ง

### 🔧 จัดการ QR เสีย (แอดมินรู้ก่อนผู้ใช้)

**1. ได้แจ้งเตือน QR** (จากงานเบื้องหลังทุกคืน หรือจากเจ้าหน้าที่ระหว่างวัน)
- เห็นรายละเอียด : ตู้ไหน · ใบไหน · สาเหตุ
  - สาเหตุที่เป็นไปได้ : พิมพ์แทนสแกน / สแกนช้า / เจ้าหน้าที่แจ้งเสีย / ไม่ใช่ของระบบ / ไม่มีคนสแกน / มีคนใช้ใบ 2 / ครบอายุ

**2. อาจเป็น QR ปลอม?**
- ใช่ → 🚨 ส่งช่างไปตรวจด่วน + แจ้งหัวหน้าโซน → ช่างลอก QR ปลอม + ติดใบใหม่ → ไปข้อ 5
- ไม่ใช่ → ไปข้อ 3

**3. ใบ 2 ยังอยู่ในตู้ไหม?**
- ยังอยู่ → 📮 แจ้งเจ้าของบ้าน "กรุณาเอา QR ใบ 2 ในตู้ไปติดหน้าตู้แทน" → ไปข้อ 4
- ใช้ไปแล้ว → ออกใบใหม่ 2 ใบ → ช่างไปติดใบ 1 + เก็บใบ 2 ในตู้ → ไปข้อ 5

**4. รอเจ้าของบ้านทำ**
- รอเจ้าของบ้านกดยืนยันในแอป หรือรอจนมีการสแกนใบ 2 เข้ามา
- จากนั้น ปิดรหัสใบเก่า (ใช้ไม่ได้แล้ว) → ออก QR ใบใหม่เป็นใบสำรอง → ส่งให้เจ้าของบ้าน (ไปรษณีย์ / ช่างนำไปให้)

**5. ✅ บันทึก** สถานะ QR → ปกติ + เก็บประวัติการเปลี่ยน

**ป้องกันตั้งแต่ต้น**
- พิมพ์ QR แบบทนความเสียหายสูงสุด + เคลือบกันแดดกันน้ำ
- เปลี่ยน QR ทุก 12 เดือน (ระบบเตือนล่วงหน้า)
