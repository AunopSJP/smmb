## แนวทางที่เลือกต่อบทบาท

| บทบาท | แนวทาง | หัวใจ |
|---|---|---|
| เจ้าของบ้าน | C ตอนปกติ + B ตอนมีปัญหา | ปกติ = ประโยคเดียว "บ้านคุณปลอดภัย · ตรวจล่าสุด …" + ปุ่มหลักเดียว · ตู้มีปัญหา = การ์ดเดียวบอกทางแก้ แบนเนอร์ย่อเป็นแถวเล็ก |
| แอดมิน (มือถือ+คอม) | B ป้ายสถานะ | ปัญหาที่ต้องจัดการเป็นพระเอก · สถิติ 7 ใบ → แถบตัวเลขบรรทัดเดียว · หน้า "ระบบ" จัดกลุ่มตามเรื่อง ไม่ซ้ำเมนูซ้าย |
| เจ้าหน้าที่ | A สมุดตรวจเวร | หน้าสรุปเหลือ "บ้านถัดไปที่ต้องตรวจ" + ปุ่มสแกน · ผลตรวจเป็นตราประทับ · เวลาเป็น mono |
| หัวหน้า | A สมุดตรวจเวร | ความคืบหน้าเป็นแถบเวรเดียว แทนช่องสถิติ 4 ช่อง · รหัสกลุ่มฟอร์แมตเดียว |
| ไรเดอร์ / ล็อกอิน / error | C คำถามเดียวต่อหน้า | ปุ่มหลักใกล้นิ้ว ไม่ว่างครึ่งจอ ไม่ใช้ปุ่มเทา disabled |
| โลโก้/ไอคอนแอป | วาดใหม่แบน สีเดียว | เลิกตู้จดหมายสามมิติเงามัน |

## ลำดับงาน (เสนอ)

1. เจ้าของบ้าน (`pages/owner-home.*`, `pages/owner/*`)
2. แอดมิน (`pages/admin/*`, `admin-home.*`)
3. เจ้าหน้าที่ + หัวหน้า (`pages/officer/*`, `pages/head/*`)
4. สาธารณะ: ไรเดอร์ ล็อกอิน error + โลโก้

## กติการ่วม (ทุกรอบ)

- ใช้ token เดิมใน `styles.scss` (`--fs-*`, `--radius-*`, `--ease-out`) ห้ามฮาร์ดโค้ด
- ต้องครบ 3 โหมด easy/default/advanced และธีมสว่าง/มืด · ตรวจที่ 390 / 768 / 1440
- สีมีความหมายเดียว: แดงแบรนด์เฉพาะปุ่ม/ลิงก์/ตัวที่เลือก · เขียว=สำเร็จ ส้ม=ต้องดู แดง=ปัญหา
- ข้อมูลเดียวกันฟอร์แมตเดียวกัน (เช่น รหัสกลุ่ม `PX7K-2MQ9`) · ข้อความไทย+อังกฤษ
- ป้ายสถานะรูปทรงเดียว · ตัวหนาใช้แยกลำดับความสำคัญ ไม่ใช่ทุกค่า
- motion ตาม `--dur-*`: กด scale 0.97 · ไม่ animate layout · เคารพ reduced-motion
- ห้ามบอกเจ้าหน้าที่เรื่อง Snapface และกฎความเป็นส่วนตัวใน CLAUDE.md ไม่เปลี่ยน

## ผลตรวจส่วนที่เคยค้าง (ตรวจแล้ว 2026-11-18)

**แก้ข้อสรุปเดิม:** หน้าหลักเจ้าของบ้านที่ถ่ายรอบแรกเป็น **โหมดละเอียด** (บัญชีทดสอบตั้งไว้) กริดสถิติ 3 ช่องตัวหนาจึงมีเฉพาะโหมดนั้น โหมดปกติเหลือ 2 ช่อง ตัวที่ผิดจริงคือ: (1) แบนเนอร์เหลือง + การ์ดตู้ออฟไลน์ + รายการสาเหตุ 3 ข้อ + ปุ่มสองปุ่ม + แถบ SOS ลอยทับเนื้อหา ซ้อนกันทุกโหมด (2) โหมดง่ายยังแสดงรายการสาเหตุ 3 ข้อครบ ยังไม่ใช่ "คำถามเดียวต่อหน้า"

| หน้า | พบ | ผลต่อแผน |
|---|---|---|
| เจ้าของบ้าน · ตั้งค่า | "ข้อมูลทางเทคนิค" (สถานะ Wi-Fi mono) โชว์ในโหมดละเอียดเท่านั้นถูกแล้ว แต่ป้ายแก้ไข/แดงปนทุกแถว | แนวทาง B: แถวเส้นบาง ปุ่มแก้ไขเป็นสีรอง |
| เจ้าของบ้าน · ประวัติ | การ์ดละ 3 บรรทัด ซ้ำ "QR หน้าตู้ · เวลา" ทุกใบ ไอคอนสี่เหลี่ยมเดียวกันหมด | ย่อเป็น 2 บรรทัด จัดกลุ่มตามวัน แยกสีเฉพาะ "ของมาส่ง" |
| เจ้าของบ้าน · Wi-Fi | ไอคอนวงกลมแดงขีด "−" สองจุดในแถวสถานะ ความหมายไม่ชัดและดูเหมือนเออเรอร์ · ย่อหน้ายาวสองก้อน | แทนด้วยข้อความ "ยังไม่ได้" · ตัดย่อหน้าเหลือขั้นตอน 3 ข้อ |
| เจ้าของบ้าน · แจ้งช่าง | งานก่อนหน้า: หัวเรื่องกับรายละเอียดต่อกันในบรรทัดเดียว ("ช่างทำเสร็จแล้วบัด 14 พ.ย.…") **น่าจะเป็นบั๊กเลย์เอาต์** | แก้เป็นบรรทัดแยก (ตรวจโค้ดก่อน) |
| เจ้าของบ้าน · หน่วยงานใกล้บ้าน | แผนที่ว่างเต็มจอ + empty state วงกลมแดงเครื่องหมายอัศเจรีย์ (ไม่ใช่ error) | ใช้ไอคอนกลางสีรอง ข้อความบอกว่าต้องปักหมุดก่อนและปุ่มไปปักหมุด |
| เจ้าของบ้าน · ข้อมูลของฉัน | กล่องเตือนซ้อน 3 ชั้น + โชว์รหัสภายใน `BOX_BOUND` ให้ผู้ใช้เห็น (ขัดกฎข้อ 10 แนวคิด: โค้ดไม่ใช่ข้อความ) | ซ่อนรหัสไว้เฉพาะโหมดละเอียด ลดกล่องเหลือหนึ่ง |
| ตั้งค่าการแจ้งเตือน (ทุกบทบาท) | สวิตช์เขียวสด 8+ ตัวเหมือนกันหมด สีเขียวขัดกับ "เขียว=สำเร็จ" | สวิตช์สีกลาง/สีแบรนด์ จัดกลุ่ม "ปิดไม่ได้" แยก |
| แบบการใช้งาน | ตัวอย่างโหมดเป็นภาพจำลองขนาดเล็กแบบหน้าจอมือถือ ดูดีและสื่อ ใช้ต่อได้ | คงไว้ |
| สมัคร: เลือกประเภท / เจ้าของบ้าน / เจ้าหน้าที่ / หน่วยงาน | หัวข้อฟอร์มสีแดงชมพู ใหญ่ซ้ำทุกการ์ด ว่างครึ่งล่างจอ · แถบ 1–4 ขั้นดี · การ์ดพับ "ไม่บังคับ" ซ้อนดี | ใช้หัวข้อสีปกติ · ปุ่ม "ถัดไป" ติดล่างจอ |
| ข้อตกลง | กล่องแรกกรอบแดงเด่นถูกแล้ว (SOS ไม่แทน 191) กล่องอื่นเหมือนกันหมด หัวเรื่องหนาเท่ากัน | คงกรอบแดงเฉพาะข้อแรก ที่เหลือแบบเรียบ |
| ไรเดอร์ (QR ผิด / ส่งถี่) | ไอคอนในวงกลมสีเหลืองกลางจอ ซ้ำรูปแบบกับหน้า offline | ใช้โครงเดียวกับ C: ปุ่มหลักใกล้นิ้ว ตัดวงกลมไอคอน |
| ไรเดอร์ · ส่งของ (ไม่มี token) | ข้อความบรรทัดเดียวบนสุด ว่างกว่า 80% | ใช้หน้า error ร่วม |
| โหมดสว่าง (เจ้าของบ้าน) | อ่านง่ายกว่ามืด การ์ดเทาสว่างปุ่มรอง "ตั้ง Wi-Fi ใหม่" ติดกับปุ่มแจ้งช่างแบบคู่ขนานดูเท่ากัน | ให้ปุ่มแนะนำหลักเดียว (ตามสถานการณ์) อีกปุ่มเป็นลิงก์ |
| โหมดง่าย | รายการสาเหตุ 3 ข้อยังอยู่ ปุ่ม 2 ใหญ่ซ้อน แถบ SOS ทับเนื้อหา | ตามแนวทาง C: ข้อความเดียว + ปุ่มเดียว |

## การตัดสินใจเพิ่ม (ผู้ใช้เลือก 2026-11-18)

- **สวิตช์แจ้งเตือน:** สีแดงแบรนด์เมื่อเปิด (เลิกเขียวสด · เขียว = สำเร็จเท่านั้น)
- **รหัสภายใน (เช่น `BOX_BOUND`):** แสดงเฉพาะโหมดละเอียด · โหมดปกติ/ง่ายเห็นข้อความที่แปลแล้ว
- **หน้าหลักเจ้าของบ้านตอนตู้ออฟไลน์:** การ์ดปัญหาใบเดียวที่บอกทางแก้ · แจ้งเตือนย่อเป็นแถวเล็ก · ข้อมูลตู้พับไว้ · SOS ติดล่างคงที่
- **โหมดง่าย:** ข้อความเดียว + ปุ่มเดียวทุกหน้าหลัก (สาเหตุ/ขั้นตอนไปอยู่หน้าถัดไป) · ต้องทดสอบกับผู้ใช้จริง
- **เจ้าหน้าที่ · สรุป:** เด่นสุดคือ "บ้านถัดไปที่ต้องตรวจ" + ปุ่มสแกน · รายการที่ตรวจแล้วเป็นแถวบาง
- **เจ้าหน้าที่ · ผลตรวจ:** ตราประทับ "ตรวจแล้ว 10:21" ใช้กับผลตรวจเท่านั้น (ต้องออกแบบให้อ่านได้ทั้งไทยและอังกฤษ)
- **หัวหน้า · ภาพรวม:** แถบเวรเดียว "ตรวจแล้ว X/Y · ตู้ออฟไลน์ · SOS" แทนช่องสถิติ 4 ช่อง
- **แอดมิน · ภาพรวม:** "ต้องจัดการ" เป็นพระเอก · สถิติเป็นแถบเดียว · ลัดไปอยู่เมนูข้าง
- **ไอคอนแอป:** SVG แบนหลายโทนเล็กน้อย (สไตล์ flat icon · ผู้ใช้เลือก) ขาว/เทาอ่อนบนแดงหม่นแบรนด์ · ทรงตามตู้จริง (กรอบดำมุมมน + แผงแดง + ช่องหยอด) + QR หน้าตู้ + กล้อง + Wi-Fi + แผงโซลาร์ · ผู้ใช้เลือกแบบ C แบบลดรายละเอียด (ไม่มีซอง/กุญแจ/เส้นตารางโซลาร์) · ไม่มีเงา/ไล่สี/ตัวอักษร · วาดเอง ไม่ลอกงาน Flaticon
- **แผนที่หน่วยงานใกล้บ้าน:** คง OSM แต่ทำให้จางลง (ฟิลเตอร์สี/เทา) และพับไว้ ไม่เต็มหน้าจอ
- **หน้าสมัคร:** หัวข้อฟอร์มสีปกติขนาดเล็ก · ปุ่ม "ถัดไป" ติดล่างจอ
- **วิธีส่งงาน:** แก้ทีละบทบาท ทดสอบ 3 โหมด แล้วหยุดให้ดูก่อน · ไม่ commit เองจนกว่าจะอนุมัติ
