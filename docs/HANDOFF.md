## 3. การตัดสินใจสำคัญ (อย่าย้อน)

1. ตู้**อ่าน QR** (+ ปุ่มส่งของหน้าตู้ 2026-10-27) — ไม่ถ่ายรูป ไม่มี RFID / IR / PIR / ไซเรน / SD card (RFID ถูกตัดทั้งหมด แทนด้วย QR ประจำตัวบนมือถือ)
2. ตรวจตู้ = สแกน QR หน้าตู้ในแอป → เซิร์ฟเวอร์ปลุกตู้ → QR ประจำตัว (30 วิ ผูกกับ job) → กล้องตู้อ่าน → **เซิร์ฟเวอร์ตัดสิน** (ตู้ไม่ตัดสินเอง)
3. **ไม่ตรวจนอกเวลาตรวจ** · **ไม่บันทึกออฟไลน์แล้วซิงก์ทีหลัง** · ลองได้ 3 ครั้ง
4. ตู้: ในเวลาตรวจหลับเบา + long-poll · นอกเวลาหลับลึกไม่รับงาน (วิธี D) · **HTTPS ไม่ใช้ MQTT** · HMAC ทุกคำขอ
5. **เว็บแอปอย่างเดียว** (Angular) เปิดนอก LINE · Web Push · ไม่มี LINE Notify/LIFF/แอป store · ไม่มี OTP · ไม่มีชำระเงิน (ฟรีช่วงทดลอง — แต่**เก็บข้อมูลแพ็กเกจ**ไว้แสดงผลแล้ว 2026-10-27)
6. 5 บทบาท Role + Level · หัวหน้า = เจ้าหน้าที่ + สิทธิ์จัดการ (หลายคนได้) · ช่างใช้บัญชีแอดมิน
7. หน่วยงานสมัคร → แอดมินอนุมัติ · เจ้าหน้าที่สมัครด้วยรหัสกลุ่ม → หัวหน้ายืนยัน · **หัวหน้าสร้างโซน** (บ้าน + คน + เวลาตรวจ)
8. บ้านต้องอยู่ในโซนก่อน การตรวจ/SOS ถึงจะถึงเจ้าหน้าที่ · ไม่อยู่ → SOS บอกโทร 191/1669 ทันที
9. QR หน้าตู้ 2 ใบ + Activate QR · QR หน้าตู้เป็นลิงก์ใช้ได้ทั้งไรเดอร์ (กล้องมือถือ) และเจ้าหน้าที่ (ปุ่มในแอป) · ไรเดอร์**กดปุ่มหน้าตู้**แทนสแกนได้ (2026-10-27)
13. แพ็กเกจผูกกับ**บัญชีเจ้าของบ้าน** เริ่มต้น**ฟรี** · หัวหน้าเห็น**ทุกโซน**ของหน่วยงาน (มีตัวกรอง)
14. (2026-10-27) **1 เบอร์หลายบทบาท** · แอดมินห้ามมีบทบาทอื่น · ตรวจตู้ตัวเองไม่ได้ · SOS ไม่ส่งหาตัวเอง · ฐานข้อมูลตั้งชื่อ `*_tb` / `*_id` / `*_date` แต่ API ใช้ชื่อตาม api.md ผ่าน mapper · PostgreSQL + Redis
10. **Log ทุกการสแกน/พิมพ์รหัส แม้ไม่ผ่าน**
11. ข้อมูลส่วนบุคคลตัดที่ server (ตารางใน api §11) · เบอร์โทรเห็นได้เฉพาะตอน SOS เปิดอยู่
12. prototype สำหรับนำเสนอลูกค้า: **กรณีผิดพลาดแยกเป็นหน้าต่างหาก** (เช่น ล็อกอินไปหน้าหลัก `H03` ไม่ใช่หน้ารหัสผิด) และ**ไม่มีเลื่อนหน้าอัตโนมัติ**

## 5. Gotchas

- **ลิงก์ prototype ข้าม page** — FigCraft รับลิงก์แบบนี้ แต่**ยังไม่ได้ยืนยันว่าตอน Present กดข้ามได้จริง** (เช่น SOS จากหน้าใหม่ → `H09`, ล็อกอิน → `H03`) · **ใน Figma ลิงก์ข้าม page ใช้ไม่ได้แน่นอน** → ถ้าย้ายไป Figma ต้องรวมหน้าที่ลิงก์กันไว้ page เดียว หรือยอมให้บางปุ่มตาย
- **ปุ่มที่ตั้งใจให้กดไม่ได้**: `O01-b`, `O01-d`, `A06-b` (สถานะ disabled ในหน้าจอ) — ไม่ใช่ลิงก์หาย
- **หน้าที่ "ไม่มีทางเข้า"** = หน้าแสดงสถานะ/กรณีผิดพลาด อยู่ในแถว "กรณีอื่น" ของแต่ละ section ไว้เปิดโชว์ตรง ๆ ตอนนำเสนอ
- **ธีมมืด/English เป็นหน้าตัวอย่างอย่างละหน้า** (`H03-D`, `H03-EN`, `O01-N`) — กดแท็บจากหน้านั้นจะกลับไปหน้าธีมสว่าง/ภาษาไทย · "ใหญ่" กับ "ใหญ่มาก" ไปหน้าเดียวกัน (`H03-L`) · ใน `O13-b` ตัวเลือก English และขนาดตัวอักษรยังไม่มีลิงก์
- **กด Ctrl+Z ใน FigCraft แล้วงานหายหลายขั้น** (เกิดแล้ว 2026-10-26 — ย้อนไป 5 ขั้น) → กู้ด้วย Redo ได้ตราบที่ยังไม่แก้อะไรต่อ · ดูประวัติได้จาก `inspect_document` → `history.undo/redo`
- **ฟอนต์**: ไฟล์ใช้ Leelawadee UI (มีในทุกเครื่อง Windows) · เปิดใน Figma บนเว็บต้องลง Figma Font Installer ก่อน · ถ้าเปลี่ยนเป็น IBM Plex Sans Thai Looped ต้องติดตั้งบนเครื่องที่เปิด FigCraft ก่อน แล้วค่อยเปลี่ยนทั้งไฟล์ (Bold → Bold, Regular → Regular) แล้วเช็กข้อความล้นทุกหน้า
- **ส่งออก `.fig` เป็นฟีเจอร์ทดลอง** — ถ้าเปิดใน Figma แล้วเงา/โลโก้/auto layout เพี้ยน ให้ดูที่ต้นฉบับ `.figcraft`
- **Web Push**: ในเบราว์เซอร์ของ LINE ใช้ไม่ได้ · iPhone ต้องเพิ่มลงหน้าจอหลักก่อน · LINE Notify ปิดบริการแล้ว — อย่าเสนอกลับมา
- **เอกสารเก่าใน memory/แชทเก่ายังพูดถึง RFID, ถ่ายรูป, LIFF, Flutter, MQTT** — ทั้งหมดถูกแทนแล้ว (design §16) ยึดเอกสาร 22 ต.ค. เป็นหลัก
- **โดเมน `smmb.app` ในเอกสารเป็นแค่ตัวอย่าง** — dev ใช้โดเมนอื่น · ห้ามฮาร์ดโค้ด ใช้ env `PUBLIC_BASE_URL` / `QR_ALLOWED_HOSTS` · คีย์ลายเซ็นแยกต่อ environment · **ต้องได้โดเมนจริงก่อนพิมพ์ QR บ้านนำร่อง** (พิมพ์แล้วเปลี่ยนโดเมนไม่ได้) — design §5.1, api §0
- **คำบนหน้าจอ ≠ คำในเอกสารเทคนิค** — หน้าจอใช้ "QR หน้าตู้ / QR สำรอง / QR เปิดใช้ตู้ / ประวัติ" · เอกสาร/โค้ดใช้ `slot 1/2/activate`, `scan_logs`
- **พิมพ์ผิดที่เคยเจอในข้อความที่ผู้ใช้วาง**: "ส4าพ", "สภภาพ" → "สภาพ"

- **นำเสนอ prototype ให้ลูกค้า** → ก่อนนำเสนอ: ลองกด Present ทุก flow ดูว่าลิงก์ข้าม page ทำงาน · เก็บ feedback เรื่องสมาชิกในบ้าน (design §12)
- **wireframe ตามเรื่องที่เพิ่ม 2026-10-27**: แถว "แพ็กเกจ: ฟรี" ใน `H13` · ส่วนแพ็กเกจในหน้าผู้ใช้ `D09` (+ แสดงใน `D04`) · ตัวกรองโซนใน `L04`/`L08` + ป้าย "โซนที่ฉันอยู่" ใน `L06` · ไรเดอร์: บอกว่ากดปุ่มหน้าตู้ได้ (`R01`/`R02`) + `T01` เช็กลิสต์ทดสอบปุ่ม
- **ปุ่มหน้าตู้ (ฮาร์ดแวร์)** — คุยกับพี่ตั๋ง: ตำแหน่ง/กันน้ำ · ต่อขาที่ปลุกตู้จากหลับลึกได้ · ไฟบอกผล · กินไฟต่อการกด 1 ครั้ง
