เกณฑ์เดียว
ที่ใช้ตัดสิน

ไม่ใช่ “สวยแบบไหน” แต่คือ “คน 9 ขวบที่อ่านช้าที่สุด กับคน 60 ปีที่สายตาไม่ดีที่สุด ทำได้โดยไม่มีใครสอนหรือไม่”

01

หนึ่งจอ หนึ่งการตัดสินใจ

ทุกจอมีปุ่มหลักเพียงปุ่มเดียว ที่เหลือเป็นทางเลือก-secondary ที่ไม่แย่งสายตา

02

คำก่อนไอคอน

ไม่มีไอคอนลอยเดี่ยว ๆ ที่ต้องเดา — ทุกไอคอนมีป้ายกำกับ และป้ายต้องอ่านออกที่ 13px

03

ตัวอักษร 17–19px

เนื้อหาไม่ต่ำกว่า 17px · ปุ่ม 19px · บรรทัดยาวไม่เกิน 34 ตัวอักษรในโหมดง่าย

04

เป้าสัมผัส 56–88px

ไม่มีปุ่มเล็กกว่า 44px · แถวรายการขั้นต่ำ 64px · เว้นช่องว่างระหว่างปุ่มที่ทำลายข้อมูล

05

สถานะเป็นประโยค

ไม่ใช้สีหรือตัวเลขเดี่ยว — “ตู้ทำงานปกติ” มาก่อน “86%” และมีคำอธิบายว่าต้องทำอะไรต่อ

06

ทางออกต้องมองเห็น

ย้อนกลับ/ยกเลิก/ปิด อยู่ทุกจอ ไม่มี gesture ซ่อน ไม่มีปัดเพื่อลบ ไม่มีหน้าจอที่ออกไม่ได้

07

ฉุกเฉินต้องมีคนรับ

SOS = กดค้าง 3 วิ → บอกว่าใครรับ → ถ้าไม่มีเจ้าหน้าที่ ให้โทร 191/1669 ทันที พร้อมปุ่มโทร

08

ข้อมูลเทคนิคซ่อนได้ ไม่ใช่หาย

โหมดละเอียดเข้าถึงรหัส/เวลา/แบตได้ แต่โหมดง่ายเห็นเฉพาะสิ่งที่ต้องทำ

ไม่ทำ

✕ gradient ม่วงบนพื้นขาว ✕ glassmorphism ✕ ไอคอนเดี่ยวไม่มีป้าย ✕ ปุ่มเล็กกว่า 44px ✕ สถานะด้วยสีอย่างเดียว ✕ auto-carousel ที่ต้องรอ ✕ ตัวเลขเทคนิคในโหมดง่าย ✕ ปัด/กดค้างแบบซ่อน (ยกเว้น SOS ที่มีป้ายบอก)

05 / 05

เลือกแบบไหน
สำหรับบ้านคุณ

ทั้งสามแบบพร้อมใช้ ไม่มีอันไหน “ถูกที่สุด” — ขึ้นกับว่าคนที่คุณกลัวว่าเขาจะกดพลาดคือใคร

ถ้าคนหลักคือเจ้าของบ้านสูงอายุ

เริ่มที่ B หรือ C

B ให้ความมั่นใจด้วยรูปตู้ที่เปลี่ยนท่า — เห็นปุ๊บรู้ปั๊บว่ามีจดหมายหรือมีปัญหา
C ให้ความเรียบง่ายที่สุดเมื่อต้องทำครั้งแรกโดยไม่มีใครช่วย

แนะนำ C สำหรับ onboarding
ถ้าต้องรองรับเจ้าหน้าที่และแอดมิน

ใช้ A เป็นภาษากลาง

ตารางจริงบนจอกว้าง ป้ายขั้นตอนชัด และตัวอักษรใหญ่พอสำหรับใช้งานกลางแดด
เหมาะกับทีมที่ทำงานเร็วและต้องเห็นข้อมูลหลายอย่างพร้อมกัน

แนะนำ A สำหรับทีมปฏิบัติการ
ถ้าจะเปิดนำร่องหมู่บ้านเดียว

เริ่ม C แล้วขยายเป็น B

C ลดความผิดพลาดในช่วงแรกและเก็บ feedback ได้ตรงที่สุด
เมื่อผู้ใช้คุ้นแล้ว ค่อยเพิ่มความอบอุ่นและบริบทของ B ในหน้าหลัก

แนะนำ C → B
?

ข้อเสนอตรง ๆ: ใช้ C กับ SOS/onboarding · B กับหน้าหลักเจ้าของบ้าน · A กับเจ้าหน้าที่/แอดมิน

ทั้งสามแบบใช้ token ชุดเดียวกัน (สี แดงหม่น แดงฉุกเฉิน เขียวสำเร็จ เทากลาง) และโครงข้อมูลเดียวกัน จึงผสมได้โดยไม่กลายเป็นสามผลิตภัณฑ์ — แต่ถ้าต้องเลือกหนึ่งแบบทั้งระบบ ผมเลือก C เพราะเป็นแบบเดียวที่คน 60 ปีใช้ได้โดยไม่ต้องมีใครนั่งข้าง
